# DeltranslatePatch Optional Patches
These are optional patch overrides for [DeltranslatePatch](https://github.com/Lazy-Desman/DeltranslatePatch), mainly for making it work with [DeltaQuick](https://play.google.com/store/apps/details?id=com.bookerpuzzle.deltaquick).

DeltaQuick patches and custom chapter-specific touch controls: [@eltiovyn](https://gamejolt.com/games/android-deltranslate-project/1086889)
