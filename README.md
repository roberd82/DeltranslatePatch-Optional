# DeltranslatePatch for Deltaquick
These are the patch overrides for [DeltranslatePatch](https://github.com/Lazy-Desman/DeltranslatePatch) that make it work with [DeltaQuick](https://play.google.com/store/apps/details?id=com.bookerpuzzle.deltaquick).

Patches based on and custom chapter-specific touch controls: [@eltiovyn](https://gamejolt.com/games/android-deltranslate-project/1086889)
